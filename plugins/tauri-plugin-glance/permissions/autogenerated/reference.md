## Default Permission

Lets the app update the widget and Live Activity.

#### This default permission set includes the following:

- `allow-update`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`glance:allow-update`

</td>
<td>

</td>
</tr>

<tr>
<td>

</td>

</td>
