# 020 IntAssis: LAR that talks, and knows your notes

**Status:** building. The direction was approved with the plan on 2026-10-15; the user confirms the wording of the criteria in this PR.

## What changes for the student

LAR answers in front of them, word by word, remembers the conversation after the app closes, and says which of their notes an answer came from. Inside a note, one "Ask AI" button summarizes, tidies or explains it. Everything still runs on the phone, and nothing changes unless the student confirms.

## Direction and references

- ADR 0003 (on-device AI, opt-in, no AI command writes). Core side: PRs for RAG, streaming, routing and `ai_note`.
- Rules pick the action and answer exact questions (due, classes, grades) without the model; only open questions reach it.

## Keep

- Light is the default; nothing downloads unless the student asks.
- The LAR orb, the bottom chat sheet, instant answers, confirm cards ("Not now" or the gold button), Why? after a wrong card.
- Nothing is written without the student's tap.

## Behaviour

- **C1.** An open question's reply appears word by word as it is written; before the first word, "Thinking" dots show. A Stop button replaces Send while LAR writes, and tapping it keeps the words so far.
- **C2.** The chat is still there after closing and reopening the app. "New chat" empties it and asks nothing first.
- **C3.** When LAR was shown notes for an answer, one chip per note sits under the reply ("From: MATH 101 · Mathematics"). Tapping a chip opens that note.
- **C4.** From the You tab, "Add IntAssis" downloads the chat model and the small note-search model together; one progress bar covers both. Removing IntAssis removes both and empties the chat.
- **C5.** The Ask AI bar has a Chat button. It opens the chat sheet above the editor; LAR then reads the open note, and the starter chips lead with "Summarize this note".
- **C6.** The note editor has an "Ask AI" button when IntAssis is on, and none when it is not. It opens a bar with Summarize, Tidy up, Explain (needs selected words) and a question box.
- **C7.** The result of an Ask AI action streams into a card above the keyboard with "Insert below", "Replace" (Tidy only) and "Discard". Nothing in the note changes until a button is tapped, and Replace can be undone once.
- **C8.** Errors are one plain sentence in the student's language (English or Filipino); no code strings, no token counts.
- **C9.** First run asks "Light or With AI?" once, Light preselected, with the download size and a Wi-Fi hint. Skipping it is the same as Light.
- **C10.** The IntAssis card says only what LAR can do: schedule, grades and notes questions, notes actions, flashcards from a topic.
- **C11.** A question about the student's own data that nothing the app holds can answer (a class on another day, a grade with no grading set up, a professor or tuition with no matching note) gets a short "I don't have that" in the student's language, without calling the model.

## Copy

- Thinking: "Thinking"; waking: "Waking up". Stop: "Stop". New chat: "New chat". Source chip: "From: {note heading}".
- Ask AI bar: "Summarize", "Tidy up", "Explain", "Ask about this note…", "Chat". Result actions: "Insert below", "Replace", "Discard".
- Errors: from `assis::friendly` (EN/Filipino), e.g. "That was too long for me. Try a shorter question."
- First run: "Light" / "With AI · {size}". Light: "No AI. Nothing downloaded." With AI: "Ask LAR about your classes and notes. One-time download, works offline."

## Data shape

- `ai_ask(now, message, openKey?, onText)` returns `{reply, proposal, sources:[{key,title}]}`; `ai_history()` returns `[{role,text,at,ask}]`; `ai_clear_history()`; `ai_index()`; `ai_note(mode,text,selection?,question?,onText)` returns text. `src-tauri/src/ai.rs`.
- Chat turns: `turns` table, last 60, `crates/intportal-core/src/store.rs`; cleared by sign-out, wipe and New chat.

## Errors

| Case | The student sees |
|---|---|
| Model busy | "I'm still working on your last message. Give me a second." |
| Not downloaded | "Turn IntAssis on first, in the You tab." |
| Not enough memory | "This phone doesn't have enough free memory right now. Close other apps and try again." |
| Note empty / too long / nothing selected | The sentence from `note::run`, e.g. "Select the words to explain first." |
| Notes could not be searched | The answer comes from the schedule alone; nothing is shown about it |

## Motion and Reduce Motion

The thinking dots step at 2 fps; under Reduce Motion they are static dots. Streamed words appear without animation either way.

## Accessibility

Send and Stop are the same button position with different labels. Chips and bar buttons are at least 40 px high. The log is a polite live region, announced when a reply finishes, not per word.

## Out of scope

Voice input (the keyboard's dictation covers it), a larger model, PDF text as a source.
